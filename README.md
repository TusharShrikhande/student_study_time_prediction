# 🎓 Student Study Time Prediction

## 📌 Project Overview

This project predicts the number of study hours of students using the **Linear Regression** algorithm from Scikit-learn.

The project demonstrates a complete machine learning workflow including:

- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Model Training
- Prediction
- Performance Evaluation

---

## 📂 Dataset

Dataset Name:

**Student Performance Dataset**

Target Variable:

- study_time_hours

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

---

## 📊 Machine Learning Algorithm

Linear Regression

---

## 📋 Data Preprocessing

The following preprocessing steps were performed:

- Removed unnecessary columns
- Converted categorical Yes/No values into numerical values
- Split the dataset into Training and Testing sets

---

## 📈 Evaluation Metrics

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
